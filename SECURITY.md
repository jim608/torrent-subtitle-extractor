# Security Policy

## Supported version

Security fixes are currently targeted at the latest code on the `main` branch.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a public issue.

If GitHub private vulnerability reporting is available for this repository, use it to report the issue privately. Otherwise, open a minimal public issue that states a security report needs maintainer contact, without including exploit details, credentials, private tracker URLs, or sensitive sample data.

A useful report includes:

- Affected version or commit
- Impact and attack prerequisites
- Minimal reproduction steps
- Suggested mitigation, if known
- Whether secrets, private torrent metadata, filesystem paths, or network access are involved

## Scope

Security reports are especially useful for path traversal, arbitrary file writes, command execution, unsafe archive or subtitle handling, exposure of private tracker credentials, unsafe WebTorrent behavior, and web-interface vulnerabilities.
